# Cloud Computing Concepts Reflection

  Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud technology. Three cloud services that I frequently use are Google Drive, Facebook Messenger, and Canva. Google Drive is an example of **Software as a Service (SaaS)** because it allows users to store, manage, and share files through a web browser without installing or maintaining servers. It uses the **Public Cloud** deployment model since its services are available to millions of users over the internet. 
  Facebook Messenger is also classified as **SaaS** because it provides instant messaging, voice calls, and video calls through an online platform. Like Google Drive, it uses the **Public Cloud** because anyone with an account can access the service through the internet. Canva is another **SaaS** application. It allows users to create presentations, posters, and graphics directly in the browser without installing complex software. It also uses the **Public Cloud** deployment model because users access the same online platform while their projects are securely stored in the cloud.
  Version control is essential when working on cloud projects because it records every change made to files and allows developers to restore previous versions if mistakes occur. This is especially important when multiple people are working on the same project. Without version control, changes could easily be lost or overwritten.
    Git and GitHub make collaboration more efficient by allowing team members to work on separate branches, review code before merging, and keep a complete history of project updates. GitHub also provides issue tracking, pull requests, and documentation, making it easier to organize cloud infrastructure projects and reduce errors. As an Information Processing student, learning Git and GitHub helps me develop good software development practices and prepares me for real-world cloud computing environments where teamwork, organization, and version control are essential.
